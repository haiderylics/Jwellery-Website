# Pre-Production Manual Test Case Matrix

This matrix specifies the structured manual test cases covering functional, visual, operational, media, security, and responsive verification.

---

## Priority Legend
- **P0**: Critical Business / Security / Operational Blocker (Must pass 100% prior to any deployment).
- **P1**: High Priority Core Feature (Storefront navigation, cart accuracy, checkout handoff).
- **P2**: Normal Priority Edge Case (Boundary values, sorting nuances, secondary viewports).
- **P3**: Polish / Visual Alignment (Subtle typography, minor spacing micro-adjustments).
